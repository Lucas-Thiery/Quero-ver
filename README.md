# Pedido Irrecusável 

Um mini-projeto divertido e interativo criado para arrancar um sorriso e garantir um "Sim!". 

## Acesse o Projeto

Você pode testar a brincadeira ao vivo acessando o link abaixo:

**[CLIQUE AQUI PARA TESTAR O PEDIDO](https://lucas-thiery.github.io/Quero-ver/)** 

## Sobre

Este projeto é uma página web simples com a mecânica de um "botão fujão" (runaway button). Ao receber a pergunta "Um beijo?", o usuário se depara com duas opções: "Sim" ou "Não". A pegadinha é que, através da manipulação do DOM com JavaScript, o botão "Não" muda de posição aleatoriamente pela tela sempre que o mouse passa por cima dele, tornando o pedido, literalmente, irrecusável.

**A história do projeto:** Criei este pequeno site para a minha atual namorada, antes mesmo de começarmos a namorar. Foi uma maneira criativa, bem-humorada (e um pouquinho nerd) de fazer a pergunta!

## Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias base do desenvolvimento web:

* **HTML5:** Para a estruturação dos textos e botões.
* **CSS3:** Utilizando Flexbox para o alinhamento centralizado e estilização da interface.
* **JavaScript (Vanilla):** Responsável por calcular dinamicamente a área da janela (`window.innerHeight` e `window.innerWidth`) e usar `Math.random()` no evento de `mouseover` para reposicionar o botão de negação.
